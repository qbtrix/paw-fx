How it works

Four steps, and the first one takes a morning.

Scope

Replace this copy with your own. Panels can be different lengths on purpose: the region measures the outgoing panel and tweens its height to the incoming one, so a short tab next to a long one is the effect rather than a layout jump.

Build

The pill under the labels is a single element. Clicking a tab moves it into that tab and the spring carries it across, which is why the bar reads as one object travelling rather than four backgrounds taking turns.

Review

Every tab is a real button inside a tablist, so a keyboard reaches all four and a screen reader announces which one is current. With the script blocked the first tab stays selected and its panel stays readable.

Ship

Add or remove tabs by adding or removing a list item and the panel that carries the same data-panel value. Nothing in the effect counts them, so four is a starting point rather than a limit.
